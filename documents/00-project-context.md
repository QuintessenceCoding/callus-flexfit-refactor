# Project Context

## Objective

This project is part of the Callus Engineering Hiring Challenge.

The goal is NOT to redesign FlexFit Studio.

The goal is to improve the internal architecture while preserving existing behaviour.

Success will be measured by:

- Behaviour preservation
- Code quality
- Documentation
- Maintainability
- Ability to explain architectural decisions

---

## Primary Constraints

- Preserve current functionality.
- Avoid unnecessary feature additions.
- Keep changes incremental.
- Prefer extraction over rewriting.
- Every architectural decision must be explainable.
